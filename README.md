# Виджет банковских операций клиента
Это виджет, который показывает несколько последних успешных банковских операций клиента.
## Установка
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/git@github.com:Kirill392r/DZ.git
   ```
2. Перейдите в директорию проекта:
   ```bash
   cd DZ_4
   ```
3. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```
## Использование

Примеры использования функций:
``` python
from src.processing import filter_by_state, sort_by_date
```
# Пример использования filter_by_state
``` python
transactions = [
    {'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
    {'id': 59402872, 'state': 'CANCELLED', 'date': '2018-09-17T21:27:25.241241'}
]
executed_transactions = filter_by_state(transactions)
```
# Пример использования sort_by_date
``` python
sorted_transactions = sort_by_date(transactions)
```

## Тестирование 
В данном проекте для написания тестов была использованна библиотека pytest
Были протестированны функции: 
get_mask_card_number - Функция маскирует номер карты, оставляя видимыми первые 6 и последние 4 цифры. 
get_mask_account - Функция маскирует номер счета, оставляя видимыми только последние 4 цифры.
mask_account_card - Функция маскирует номер карты или счета в зависимости от типа.
get_date - Функция преобразует строку с датой в формате "2024-03-11T02:26:18.671407" в строку с датой в формате "ДД.ММ.ГГГГ".
filter_by_state - Функция которая возвращает новый список словарей, содержащий только те словари, у которых ключ соответствует указанному значению.
sort_by_date - Функция которая возвращает новый список, отсортированный по дате
Покрытие тестами составило более 80%.
Для запуска тестов используйте команду: 
``` python
pytest
```
Также можно посмотреть процент покрытия тестами используя команду:
``` python
pytest --cov
```
Все тесты проходят успешно.
